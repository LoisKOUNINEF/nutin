# What is the difference between options and features?

Options **can be toggled on and off**.

Features are added with `nutin-add <feature>` (see [How do I add a feature?](../CLI/HOWDOI_ADD_A_FEATURE.md)) and **can only be removed manually once added**. 

See [How do I configure Nutin?](./HOWDOI_CONFIGURE_NUTIN.md)
