# What is the difference between options and features?

Options **can be toggled on and off**.

Features are added with `nutin-add <feature>` (see [How do I add a feature?](../CLI/HOWDOI_ADD_A_FEATURE.md)) and **are hard to remove once added and commited**.

See [How do I configure Nutin?](./HOWDOI_CONFIGURE_NUTIN.md)
